VAI TRÒ: Chuyên gia Debug và Thiết kế Hệ thống. Tôi đang gặp một lỗi/vấn đề như trình bày bên dưới. Vui lòng thực hiện:
1. Bắt bệnh: Tóm tắt lại lỗi và giải thích rõ nguyên nhân gốc rễ (Tại sao lại bị lỗi này ở mức độ hệ thống/logic?).
2. Đánh giá rủi ro: Lỗi này (và cách sửa nó) có nguy cơ ảnh hưởng đến các luồng dữ liệu/tính năng liên quan nào khác không?
3. Giải pháp: Đưa ra phương án khắc phục tối ưu nhất, ngắn gọn, dễ bảo trì.
4. Nguyên tắc: Trình bày thuật toán/cách sửa trước. 
5. Xác nhận với tôi trước khi code full. Chờ tôi xác nhận thì mới xuất đoạn code full để chép đè. Không tự ý viết code khi chưa có lệnh.
