# 2026-10-15 — DGN ➔ CAD (V7/V8, Batch) và CAD ➔ DGN

## Ngữ cảnh

Civil 3D 2026. Hai chiều chuyển đổi MicroStation DGN ↔ CAD, dùng engine có sẵn của Civil (`-DGNIMPORT`, `-DGNEXPORT`), không cần MicroStation. Bump **1.6.0** (bản phát hành đầu tiên chứa D2C, Batch, C2D).

## Trạng thái đã chốt

- **D2C**: V7/V8, `DGNIMPORTMODE=2` (mode 0 lệch tọa độ), hậu xử lý chờ `Handseed` ngừng đổi, `UNDO` 2 lần. V8: bỏ tiền tố layer, giải mã text V8 + TCVN3. Batch ghép / không ghép. User xác nhận "rất tốt".
- **C2D**: hộp thoại tối màu (phạm vi, V8/V7, Purge, ghi đè), xuất qua bản sao tạm khi cần, hộp thoại báo kết quả.
- **`-DGNEXPORT`**: `[V7/V8]` ➔ tên file ➔ `[Master/Sub]` ➔ mapping ➔ seed. Seed chỉ nhận `~` (hộp thoại modal) ➔ luồng nền tự điền. Bản vẽ có Z cần seed 3D, nếu không prompt seed treo ("A 3D seed file is required").
- **Seed**: bundle `Contents\Seeds\VN2000_Seed{2D|3D}_{V7|V8}.dgn` ➔ seed metric của Civil. V7 2D/3D tự tạo từ `DC2.dgn` + khác biệt seed Civil; V8 chưa có (dùng seed Civil).
- Kiểm chứng: V7/V8 × chọn/toàn bộ × 2D/3D, nhập lại giữ X/Y/Z; DWG thật Hải Dương xuất thành công.
- Phát hiện kỹ thuật: lisp `(command ...)` và `Editor.Command` đều treo nếu sai trình tự prompt; `SendStringToExecute` bỏ dòng trống; `LASTPROMPT` trễ một bước; `DELAY` trong script tối đa 32767 ms.

## Việc mở

- Nhắc user: chuẩn hóa theo quy chuẩn (63 Level Phụ lục 21, tên layer, màu RGB Phụ lục 22, font, chữ hoa V8) cho cả D2C và C2D; user sẽ gửi thêm QCVN.
- Seed V8 chuẩn VN-2000 từ MicroStation.
- User mở DGN xuất trong MicroStation: Level, đơn vị, font tiếng Việt, view seed V7 3D.
- Batch xuất nhiều bản vẽ ➔ DGN.
- Các mục test còn mở từ 1.5.x.
