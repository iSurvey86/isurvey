# Nhập file DGN phiên bản 1.8.20

Lệnh tắt `D2C`. Lệnh đủ `ISURVEY_DGN_TO_CAD`. Hành vi có từ iSurvey 1.8.20: batch V7 tách reference trước; nếu 0 đối tượng thì lấy `*-Default*.dwg` hoặc thử lại kèm sibling. Video 1.8.15 / 1.8.17 vẫn giữ.

File máy đọc: `d2c-1.8.20.json`. Câu thoại nằm trong json. Trang này là việc phải làm trên Civil khi quay.

## Ngoài camera

Máy đã đăng nhập iSurvey. Bản vẽ mới, Model Space. Thư mục mẫu có vài file `.dgn` V7 (có thể kèm reference). Không ghi đè file người dùng đang sửa.

## Trên camera

Raw ghi vào `docs/video/thanh-pham/d2c-1.8.20/raw/<id>.mp4`.

| Cảnh | Việc trên màn hình |
|---|---|
| 01-mo-dau | Thẻ chữ, không quay Civil |
| 02-lenh | Gõ `D2C` hoặc Ribbon **Nhập DGN ➔ CAD**. Hộp «iSurvey — Nhập DGN» mở. |
| 03-them-tep | **Thêm tệp...**, chọn nhiều file `.dgn` (hoặc cả thư mục). Bảng nhiều dòng. Giữ chế độ ghép một bản vẽ. |
| 04-nhap | Bấm **Nhập DGN**. Hộp tiến trình chạy từng file đến khi xong. Không bị hỏi Master/Sub. |
| 05-ket | Thẻ chữ, không quay Civil |

Không để hộp đăng nhập, email, hay đường dẫn thư mục cá nhân chiếm khung hình.
